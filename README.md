# scam_detector
A website scam detector extension.

## Description
A Chrome extension designed to protect users by identifying and flagging suspicious websites in real-time.

<img src ="https://i.postimg.cc/wjx28xrP/Screenshot-2026-05-17-134753.png" width="600">

## What it detects
Https check
Url Length Check
Suspicious Keywords in Url check
Suspicious Keywords in webpage check

## Next Feature

Domain Age Check
